# Prepare a bilingual case study

Start with a published project page in each language. Use its existing header, player, responsive layout and footer. Keep the following worksheet private until the client approves the material.

| Field | Evidence to collect |
|---|---|
| Project and permissions | Approved client/project name, permitted markets, language, images, video cut, music and talent. Record the approver and scope privately. |
| Context and objective | Who needed the video, where it was to appear, and what the viewer should understand. |
| Production challenge | A concrete scheduling, location, format or storytelling constraint confirmed by the producer. |
| Creative and production decisions | Explain one choice, why it served the objective and what was actually filmed. |
| Deliverables | Approved edit lengths, aspect ratios, language versions and stills. Distinguish the public preview from the full delivery. |
| Results | Use an authorized observation with source, date and period. Omit unavailable results. |
| Media | Public player and poster URLs, duration, first public upload date of this exact cut, transcript or captions and appropriate image descriptions. |
| Next step | One relevant service and one inquiry CTA. Add a return link from that service when the example helps the buyer. |

Review the English and French pages side by side. Use the same project identity, evidence and outcome. Confirm each canonical and reciprocal alternate, test video playback and keyboard controls, link from the portfolio, update the sitemap and run the SEO validator. Document final sign-off outside the public repository.
